## 1. 產品摘要

**一句話**：一套 macOS 原生、離線運作、不訂閱的 PDF 編輯與文件處理工具。

**要做的事**：

- 開啟、瀏覽、搜尋 PDF，支援大檔與多分頁。
- 合併、分割、排序、旋轉、刪除、插入、擷取頁面。
- 註解、畫重點、簽名、填表單、建立表單。
- 掃描或匯入圖片，用 Apple Vision 做離線 OCR，變成可搜尋 PDF。
- 浮水印、頁首頁尾、頁碼、Bates 編號、印章。
- 壓縮、轉圖片、轉文字、PDF/A。
- 永久塗黑敏感資訊（真移除，不只是畫黑框）。
- 兩份 PDF 版本比對。
- 把上述步驟串成批次流程（Flows）。

**不做的事**：帳號、雲端同步、協作、廣告、訂閱、上傳檔案、AI 聊天。

**為什麼值得做**：現有工具不是訂閱制，就是把文件傳到雲端；這套工具的重點是「檔案不離開這台 Mac」。

## 2. 目標與成功指標

### 2.1 產品目標

1. 80～90% 的日常 PDF 工作可以在同一個 App 完成，不需要開 Preview、Acrobat、線上工具。
2. 全程離線可用；除了使用者主動點連結，不產生任何網路請求。
3. 操作可預期、可復原；破壞性操作（塗黑、壓縮、覆寫）一定要有確認與備份。

### 2.2 成功指標

| 指標 | 目標 |
|---|---|
| 100 MB／500 頁 PDF 開啟時間 | < 5 秒（M 系列晶片） |
| 連續捲動幀率 | 穩定 60 fps |
| 縮圖產生 | 每頁 < 200 ms，背景產生 |
| OCR 速度 | 每頁 1～3 秒（300 DPI） |
| 塗黑後文字萃取 | 塗黑區域內取不到任何文字 |
| 當機後恢復 | 開啟 App 後 10 秒內可選擇恢復未儲存內容 |
| 離線測試 | 關閉網路仍可使用所有核心功能 |
| 繁中介面 | 主要流程 100% 翻譯 |

## 3. 使用者與使用情境

### 3.1 主要使用者

- 你自己，以及少量內部同事。
- 日常工作會碰到：合約、報告、掃描件、申請表、講義、帳單。
- 在意隱私，不想把文件上傳到未知伺服器。
- 使用 macOS，可能同時有 Apple Silicon 與 Intel 機器。

### 3.2 核心情境（Jobs to be Done）

| 編號 | 情境 | 完成定義 |
|---|---|---|
| U1 | 拿到一份 PDF，畫重點、加註解，另存新檔 | 註解在 Preview／Acrobat 也看得到 |
| U2 | 把多份 PDF 合併，刪掉幾頁，調整順序 | 輸出檔頁序正確、可正常開啟 |
| U3 | 把掃描檔 OCR，之後可以搜尋、複製文字 | 搜尋找得到、文字可選取 |
| U4 | 把個資塗黑後傳給別人 | 存檔後無法用文字萃取還原 |
| U5 | 填寫表單、簽名， flatten 後回傳 | 對方看到的是填好的版本，不能改 |
| U6 | 把一份 PDF 的表格匯出成 Excel | 表格內容與欄位大致正確 |
| U7 | 幫一批 PDF 加浮水印、壓縮、轉圖片 | 一次跑完，有成功／失敗報表 |
| U8 | 比較合約 v1 與 v2 改了哪裡 | 看得出來新增、刪除、修改的段落 |

## 4. 產品原則

1. **Local-first**：預設不聯網、不上傳、不需要帳號。
2. **Native**：用 macOS 原生控件與 PDFKit，不包瀏覽器、不模擬行動版 UI。
3. **Non-destructive**：預設不覆寫原檔；儲存一律「另存」或明確確認。
4. **Undoable**：所有編輯都可復原；破壞性操作有備份與二次確認。
5. **Keyboard-first**：常用操作都有快捷鍵；可用鍵盤完成主要流程。
6. **Accessible**：VoiceOver、鍵盤焦點、高對比、減少動態。
7. **Boring reliability**：寧可功能少，不要存檔失敗或塗黑失效。
8. **No dark patterns**：沒有廣告、沒有假倒數、沒有訂閱牆。

## 8. 非功能需求

### 8.1 效能

- 100 MB／500 頁：開啟 < 5 秒，第一頁可見 < 1 秒。
- 縮圖：背景產生，UI 不卡；快取命中 < 50 ms。
- 連續捲動：60 fps；大幅縮放不閃爍。
- OCR：300 DPI、每頁 1～3 秒；可取消。
- 壓縮：背景執行、進度可取消。
- 記憶體：500 頁文件 < 1.5 GB；壓力時自動釋放快取。

### 8.2 可靠性

- 存檔採原子寫入；中斷不產生半個檔案。
- 崩潰／斷電後可恢復最近一次自動快照。
- 破壞性操作前自動備份到 `Application Support/Backups`。
- Undo 至少 50 步；大型文件可降級為頁面級 snapshot。

### 8.3 隱私與安全

- 預設不連網；沒有 telemetry、 Crashlytics、GA。
- 若未來加更新檢查，必須是可關閉、只連官方端點。
- 不執行 PDF JavaScript；匯入時可偵測並提示。
- 塗黑後必須通過「文字萃取為空」驗證。
- 檔案權限：sandbox + security-scoped bookmarks（推薦）。

### 8.4 相容性

- macOS 14 Sonoma 以上（建議）。
- Universal 2：Apple Silicon + Intel。
- 輸出 PDF 需能在 Preview、Acrobat Reader、Chrome 開啟。
- 不依賴網路字型；使用系統字型或內嵌字型。

### 8.5 無障礙與在地化

- 繁中優先，英文其次。
- 所有按鈕有 accessibility label。
- 主要流程可用鍵盤完成。
- 支援系統深色模式、高對比、減少動態。

## 9. 技術架構

### 9.1 選型

| 層 | 選擇 | 理由 |
|---|---|---|
| UI | SwiftUI + AppKit bridge | 原生外觀、動畫、視窗管理 |
| 文件模型 | `NSDocument` | 自動儲存、版本、最近文件、多視窗 |
| PDF 渲染 | PDFKit `PDFView` | 免費、成熟、支援註解／表單／目錄／搜尋／列印 |
| PDF 操作 | PDFKit + CoreGraphics | 頁面插入／刪除／合併／浮水印 |
| OCR | Vision `VNRecognizeTextRequest` | 本地、免費、支援中英文 |
| 影像處理 | CoreImage / ImageIO | 裁切、旋轉、壓縮 |
| 文字層 | CoreGraphics `CGPDFContext` | 隱形文字、PDF/A |
| 塗黑 | v1 rasterize；v2 `CGPDFScanner`；v3 PDFium | 漸進式 |
| 測試 | XCTest + XCUITest | 原生工具鏈 |
| 專案生成 | xcodegen | 專案檔可版控、可重現 |

### 9.2 為什麼第一版不用 PDFium

- PDFKit 已涵蓋 80% 功能，體積小、與 macOS 整合好。
- PDFium 需要自行編譯 XCFramework、處理 C++ 介面、簽章與記憶體管理。
- 等到要做「真文字編輯／content stream 塗黑」時再評估導入，避免一開始就背上大型依賴。

### 9.4 關鍵設計

**文件狀態**

```swift
@MainActor
final class DocumentSession: ObservableObject {
    let url: URL
    var pdf: PDFDocument
    var isDirty: Bool
    var undoManager: UndoManager
    var annotations: [AnnotationRef]
    var redactions: [RedactionMark]
    var recovery: RecoveryStore
}
```

**操作模式**

```swift
protocol PDFOperation {
    func apply(to doc: PDFDocument) throws -> PDFDocument
    var undoAction: (() -> Void)? { get }
}
```

- 頁面操作：先複製 `PDFDocument`，套用後替換，undo 用舊文件。
- 註解：直接改 `PDFPage` 的 annotation，undo 用 `UndoManager`。
- 塗黑：產生新頁，舊頁備份到暫存。
- 壓縮：輸出到新檔，不动原檔。

**儲存策略**

- 開啟：原檔唯讀；所有編輯在記憶體。
- 儲存：`Save` 覆寫前先寫 `.bak`；`Save As` 寫新檔。
- 自動恢復：每 30 秒或每次操作後，寫 snapshot 到 `Application Support/PDFWorkbench/Recovery/<uuid>/`。
- 原子寫入：`temp.pdf` → `rename()`。

**OCR 流程**

1. `PDFPage` → `CGImage`（300 DPI）。
2. `VNRecognizeTextRequest`（`.accurate`，語言清單）。
3. 取得 `VNRecognizedTextObservation` 與 bounding boxes。
4. 建立新 `PDFPage`：原圖 + `CGPDFContext` 隱形文字（text rendering mode 3）。
5. 快取結果（page hash）。

**塗黑流程（v1）**

1. 使用者在頁面畫框 / 選關鍵字 / 跑 PII。
2. 產生 `RedactionMark` 清單，進入審閱模式。
3. 套用：
   - 對每頁 render 成 300 DPI bitmap。
   - 在黑框位置填黑（或自訂顏色）。
   - 用 bitmap 建立新 `PDFPage`，取代原頁。
   - 移除該頁所有 annotation、link、form field。
4. 清理 metadata、attachments、outline 指向。
5. 儲存後執行 `PDFPage.string` 檢查，確認塗黑區無文字。
6. 顯示「已完成，N 頁、M 個區域」。

**比對流程**

1. 兩份文件逐頁抽取文字。
2. 頁面配對：頁面大小 + 文字相似度。
3. 文字 diff：Myers / CollectionDifference。
4. 視覺 diff：150 DPI render，像素差異，連通區域標框。
5. 結果列表 + 並排檢視。

**Flows 流程**

1. `Flow` 以 JSON 儲存（`Codable`）。
2. `FlowExecutor` 依序執行 step，回報 progress。
3. 每個 step 有 `errorPolicy`（停止／略過／重試）。
4. 輸出命名支援 `{name}`、`{index}`、`{date}`。

## 11. 資料模型與儲存

### 11.1 主要型別

```swift
struct DocumentRef: Codable {
    let id: UUID
    var url: URL
    var bookmark: Data?
    var lastPage: Int
    var lastZoom: CGFloat
}

struct RedactionMark: Identifiable, Codable {
    let id: UUID
    let pageIndex: Int
    var rect: CGRect
    var style: RedactionStyle
    var source: RedactionSource // manual, keyword, pii, ocr
}

struct Flow: Identifiable, Codable {
    let id: UUID
    var name: String
    var steps: [FlowStep]
    var input: FlowInput
    var output: FlowOutput
}

enum FlowStep: Codable {
    case compress(CompressOptions)
    case ocr(OCROptions)
    case watermark(WatermarkConfig)
    case rotate(RotateOptions)
    case split(SplitOptions)
    case redact(RedactOptions)
    case exportImages(ExportOptions)
}
```

```
~/Library/Application Support/PDFWorkbench/
├── Recovery/<document-uuid>/
│   ├── manifest.json
│   └── snapshot.pdf
├── Backups/<timestamp>-<name>.pdf
├── Thumbnails/<hash>/
```

### 11.3 檔案策略

- 表單建立。

## 13. 風險與對策

| 風險 | 影響 | 對策 |
|---|---|---|
| PDFKit 不支援 content stream 編輯 | 無法做真塗黑／真文字編輯 | v1 rasterize；v2 CGPDFScanner；v3 PDFium |
| 真文字編輯排版複雜 | 工期爆炸、品質差 | 列 M4；先做插入文字方塊 |
| PDF → Office 版面失真 | 使用者失望 | 先做文字／RTF；必要時買 SDK |
| 大檔記憶體不足 | 閃退 | tile render、分頁載入、快取上限 |
| 塗黑漏字 | 隱私事故 | 審閱 + 存檔後驗證 + rasterize 保底 |
| 沙盒檔案存取 | 無法重開最近文件 | security-scoped bookmarks |
| Undo 記憶體 | 大檔卡頓 | 頁面 snapshot + 磁碟 spill |
| 字型授權 | 嵌入爭議 | 只用系統字型／確認授權 |
| PDF 惡意檔 | 崩潰／安全 | 隔離解析、限制資源、不執行 JS |
| 測試素材不足 | 漏 bug | 建立 fixture 庫（見附錄） |

### 16.3 名詞

- **AcroForm**：PDF 表單的標準格式。
- **Content stream**：PDF 頁面的繪製指令流。
- **Flatten**：把註解／表單／圖層烤進頁面，變成不可編輯。
- **Rasterize**：把向量頁面轉成點陣圖。
- **PII**：可識別個人的資訊。
- **OCR**：光學字元辨識。
- **PDF/A**：長期保存用的 PDF 子集。
